A 批注圈（推荐）：琥珀色铅笔圈与空复选框，表示「这里等你看一眼」；0.9 秒画圈，随后复选框淡入。

B 线描云：保留天气隐喻，仅用侧栏墨色细线描云，辅以不超过 5% 的中性薄雾；1 秒描完后静止。

C 拉绳：绳子绷紧、两道刻线标出张力；布偶在 0.6 秒内升起 8px、回落 2px，停在抬高 6px 的位置。

三种待处理场景保留实线静止轴，入场后不再运动；性能模式与减少动态效果设置均直接显示静态终态。

下方两行分别是浅色、深色的 3× 对照，横向滚动查看三种样式；模式同步切换，主预览的样式选择仅影响待处理。
