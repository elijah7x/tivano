侧栏标题：统一字号与两侧边缘

以本地 dev 的布局常量为依据。每栏宽 300 CSS px，1 CSS px 对应 1pt；浅色与深色同时对照。红线标记顶层行文字 x=46 与共用右边缘 x=280。

这是代码测量稿，不是应用截图。背景为中性近似，图标为内嵌 SVG 占位；系统字形、材质与文字基线需由 lead 验收。默认 Interface=14：.ui 比 stock 大 1pt，hero 不随之缩放。A/B/C 的标题先按题设的实际 11/13/12px 展示。

为比较题设中的三组标签，演示在“对话列表”下插入了两条独立会话样本。实际 dev 中“对话列表”是固定工具栏，滚动区直接从“项目”开始；聚焦开关仅用于比较时间列，不模拟真实筛选或分组逻辑。现状中的时间实际在所有非 detailed 行可见，并非只在聚焦态显示。

差异与实施参数

  • 三个主标题分成两套：对话列表 13pt semibold / 70%，项目与任务14pt regular / 92%。后两者看起来像普通行。
  • 左边缘依次出现12、18、30、46、58。12来自胶囊按钮对齐公式，却被用于文字标题；项目/任务标题沿文字列，hero入口沿图标框列。嵌套58是层级需要，应保留。
  • 右侧搜索与plus的中心已经同为274，不是所有尾部都乱：时间/计数也已同为280。但不同按钮框分别止于290/284，不能说它们与文字共用一个右边缘。
  • hero固定13pt，其他UI随 Interface 设置偏移；上下节奏也混用工具栏32高、普通行28高、groupGap10、日期标题2/14。字体统一应同时明确缩放与留白。
  • “对话列表”在dev中是全局工具栏标题，项目/任务才是滚动分区。方案刻意统一视觉，保留其固定/滚动行为；不要为排版改动会话归属。
方案标题 / hero 入口留白与右边缘可直接采用的 Swift 参数
A · Quiet labels实际11pt semibold，secondary，tracking .2；标题与整串入口均 x46。标题前18、后4。全部尾部可见内容右280；行/嵌套几何保持。在默认UI14达到11：.ui(size:10, weight:.semibold) + .tracking(0.2)。横坐标 listInset+rowHorizontalPadding+iconSize+8；容器内leading36。改UI设置时随之变化。
B · Stronger hierarchy实际13pt semibold，primaryText.opacity(0.7)（等同secondary）；标题/整串入口 x18，沿文件夹图标框。上18、下4；除首区外，在标题上10pt加0.5pt线，从x18到280，Chrome.overlay(0.16)；尾部右280。.ui(.callout, weight:.semibold) 默认13；listInset+rowHorizontalPadding。新增线与间距仅用于侧栏标题，不改全局 ChromeSection。
C · 文字列一致（推荐）实际12pt semibold，secondary，不加字距；标题/整串入口 x46。比正文14pt小两级，中文比11pt更易读。上14、下4，无分隔线；共享右280。保留28pt行高与12pt嵌套。.ui(.subheadline, weight:.semibold) 默认12；左侧同A；颜色 Chrome.secondaryText。hero保持13 medium和中心y72，只改x。

共同实现约定：尾部文字/图形对齐线为 width − (Chrome.listInset + 10)，此处保留现有时间的20pt外边距。搜索、plus 的可见图形框统一12pt并尾端落在280；点击区域仍用原32/20pt尺寸，以 overlay 或 contentShape 独立扩展，不把可见图形居中回不同宽度容器。继续使用 ChromeIconButton / RowAccessoryIcon，需为此侧栏布局明确图形框对齐能力。hover按钮同样遵循该右边缘。

hero 的“+ 新对话”在本稿作为一整条动作标签对齐（加号左端在选定列）；若改成独立20pt加号列、让“新”本身对齐，应作为另一方案评估，不能用空格宽度伪造精确对齐。上下18/14和4以标签内容容器计；若保留1pt列表spacing，应从附加padding扣去它，避免最终变成19/15和5。

推荐 C

统一到 x46 的文字列、12pt semibold 与70%文字色，保留项目的12pt层级缩进。它比 A 的11pt更适合中文，也比 B 的分隔线更安静。先统一尾部可见内容的右边缘，再调整标题留白；别将默认UI14误当 stock13，否则成品会比设计大1pt。
