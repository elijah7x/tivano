# MiniMax Code logo

`provider-minimaxCode.imageset/mcode.svg` contains the official monochrome mascot used beside the **MiniMax Code** wordmark in the [official CLI documentation](https://agent.minimax.io/docs/cli/quick-start). It is not the generic MiniMax corporate wordmark or a terminal symbol.

- Retrieved on **2026-10-21** from the first inline SVG (top-left product mark) on [agent.minimax.io](https://agent.minimax.io/). The homepage and CLI documentation were opened in Ego Browser and their rendered branding was visually inspected during source research.
- Corroborating original vector: the documentation's [light logo SVG](https://mintcdn.com/agent-en/AWwAA_JD3rUWnMtN/logo/light.svg), whose `mark` group contains the same mascot path beside “MiniMax Code”. The full wordmark is `148.194 × 22.82`, with `viewBox="0 0 148.194 22.82"`.
- Imported source: native inline SVG, `width="28"`, `height="28"`, `viewBox="0 0 16 16"`. The original path, clipping rectangle and geometry are retained. Only the website CSS class was removed and `currentColor` was resolved to black for a standalone asset. No tracing, raster conversion, upscaling or redrawing was performed.
- Asset settings retain `preserves-vector-representation: true` and `template-rendering-intent: template`, appropriate for this official monochrome mark. Tivano supplies the display tint.
- The [official CLI repository](https://github.com/MiniMax-AI/minimax-code/tree/5821f7c9b0363a9b97a57fff3deaa4cd2da165a4) was also consulted. Its `docs/assets/wordmark-light.svg` is a wide, text-based terminal banner (`760 × 88`), not the standalone mascot imported here.

## Colour version (2026-10-23)

The asset is now `provider-minimaxCode.imageset/mcode.png` (128 × 128, rendering intent `original`), replacing the monochrome `mcode.svg` so the provider menu shows brand colours like Claude, Kimi and DeepSeek. MiniMax publishes the coloured mascot only as raster with a white background (`agent.minimax.io/assets/logo/apple-touch_v2.png`, 1024 × 1024). Its pixels were clipped by the official mascot path described above, aligned by bounding box (both 0.970 aspect) and scaled 0.5 % beyond the path so no white fringe shows, then rendered with headless Chrome on a transparent background. Geometry and colours are unchanged; nothing was traced or redrawn.
